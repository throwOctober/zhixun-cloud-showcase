# 智训云平台｜让课程任务、实训操作与过程反馈接起来

> **学生边看指导边操作，教师依据步骤检查开展实训辅导。**

课程资料、课堂活动与实训任务一多，学生需要清晰的学习路径，教师需要具体的过程依据。智训云把章节、课时任务、实训指导与网页或终端环境关联起来：学生边看指导边操作，发起步骤检查；教师结合学习进度、提交和评阅记录安排讲解与补练。AI 协助准备课程、题目与评分草稿，再由教师修改和确认。

*A teaching and practical-training platform that brings lesson tasks, guided hands-on work and process-based feedback into the same course.*

## 教学与实训如何连起来

| 特点 | 具体做法 | 带来的价值 |
| --- | --- | --- |
| **课程沿课时任务展开** | 按章节和课时组织资料、测验、课堂活动与后续任务，保存学习进度。 | 学习内容有顺序，学生可以从已有进度继续学习。 |
| **指导书与操作环境相邻** | 把实训指导、步骤和网页或终端环境关联到课时，学生边看指导边操作。 | 将课程要求落实成能动手完成、能逐步检查的任务。 |
| **辅导可以定位到步骤** | 查看进度、提交、步骤检查结果，结合评阅记录安排讲解与补练。 | 教师跟进有对应的过程依据，便于定位需要进一步指导的环节。 |
| **AI 草稿接入教师流程** | 辅助准备章节课时、客观题与评分草稿，由教师核对、修改并确认选用。 | 教师从可修改的草稿开始，同时保留内容与成绩的确认责任。 |

## 适合怎样的教学工作

- 授课教师：按课时安排学习资料、课堂活动和课后任务。
- 实训教师：将指导步骤与操作环境关联，结合步骤检查结果开展辅导。
- 教学管理者：围绕课程进度、提交和评阅记录了解教学过程。

## 实践流程

组织章节与课时 → 关联指导书和实训环境 → 学生操作与步骤检查 → 教师讲评、补练与确认

## 条件与范围

- **资源条件**：实训环境与任务模板需按教学场景配置。
- **教师复核**：AI 生成的内容和评分建议由教师核对确认。
- **展示范围**：材料展示产品模块，不承诺具体机构的实施结果。

实训环境、任务模板和 AI 服务需按教学场景配置，具体条件见演示资料。
