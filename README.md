# 智训云平台｜云实训、环境编排与证据驱动的教学反馈

> **AI 辅助准备实训，镜像与模板承载环境，操作判据形成结果，教师依据证据开展反馈。**

智训云面向高校、职业院校与培训机构，将**实训创作、环境编排、实际步骤检查、进度汇总和 AI 评阅草稿**连接起来。教师可生成指导书与检查脚本草稿，核对步骤绑定和命令后保存；学生在网页或终端环境中操作，平台分别保留实际检查结果与 AI 评阅反馈。课程、课堂、作业和成绩管理围绕这条实践路径提供支撑。

*Cloud lab and hands-on training platform: image-based environments, versioned lab orchestration, executable step checks, AI-assisted lab-guide and checker drafts, evidence-based review drafts and LMS teaching workflows.*

## 首先了解三个特色

1. **AI 辅助实训创作**：指导书和步骤检查脚本可分别形成草稿，教师补齐步骤绑定和判据后采用。
2. **镜像与版本化环境编排**：按模板校验、资源准入、创建与回收组织学习者环境；Docker/Kubernetes 等 Provider 按配置启用。
3. **实际操作与教学反馈相连**：在本人运行环境内执行检查，再汇总进度；检查证据可用于 AI 评阅草稿，教师继续复核教学结果。

## 一项实训如何组织

| 阶段 | 平台做什么 | 教师或运行条件 |
| --- | --- | --- |
| **准备指导与判据** | AI 辅助生成实训指导书和检查脚本草稿；检查器与任务步骤明确绑定。 | 教师核对内容、步骤身份、通过/失败提示及命令后保存；生成不直接发布。 |
| **配置镜像和模板** | 环境规格引用已有镜像，以模板版本组织资源、通道与运行要求。 | 按 Provider 的 Schema 校验与发布；镜像仓库、Docker/Kubernetes 和实际资源需配置。 |
| **创建并进入环境** | 参数校验、资源准入后创建环境，学生经网页或终端完成操作。 | 具体通道和环境类型以已启用能力为准。 |
| **运行步骤检查** | 在本人运行中的环境执行已配置判据，返回通过、未通过或暂不能判定。 | 命令执行、退出状态与输出共同形成检查依据；异常保留待处理。 |
| **进度与 AI 评阅** | 以服务端步骤结果汇总实训进度，将检查证据用于规则评分和 AI 评阅反馈。 | AI 评阅单独保留为未发布草稿，不自动成为课程正式成绩。 |
| **回收和复盘** | 管理状态对账、到期回收与学习记录，供讲解、补练和复核。 | 模板、判据和资源按教学场景维护。 |

## 内容创作与导入分别做什么

- **AI 文档课程生成**：分段生成、编辑、确认、回退和重试，检查上游内容一致性与课包结构后进入审核；该入口当前生成文档课时。
- **AI 实训指导与判据草稿**：是独立的实训创作入口。检查脚本需教师绑定步骤与审查命令后保存，不等同于自动生成并上线完整实训。
- **结构化实训课包导入**：将已有指导书、环境模板绑定和检查器导入为实训草稿，与 AI 文档课程生成分别使用。
- **代码作业 AI 评阅与客观题生成**：提供评阅建议、评分草稿和客观题候选，由教师核对采用。实训判题在学习者环境执行已配置的检查命令。代码作业 AI 评阅提供教师确认用的评分草稿。

## 多形态课时与教学管理

| 场景 | 支持的工作 |
| --- | --- |
| 在线教学与 LMS | 课程章节、课时、资料、学习任务、签到与课堂测验。 |
| 多形态资源 | 视频、文档、测验、作业、直播与实践课时；课堂音视频依配置接入相应服务。 |
| 作业与成绩 | 学生提交、按类型处理、教师确认评分与发布课程结果，查看成绩册和学习记录。 |
| 情景对话训练 | 学生提交文字回应并回顾参考评价，教师追加教学审阅。 |
| 职业教育与培训 | 支持本科混合教学、高职中职技能实训、机构培训和企业培训等功能场景。 |

视频与直播课时按各自的资源和服务配置使用。AI 课程生成提供文档课包。环境模板复用已有镜像，构建或推送新镜像需要独立工具与验证。
