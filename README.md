# 智训云平台｜以环境编排与执行判据驱动教学实训

> **实验环境可编排，操作成果可检查，学习进度有依据。**

智训云将课程任务、实验环境与操作判据连接起来。版本化模板描述环境与访问方式，平台管理环境的创建和回收；步骤检查在学习者的运行环境内执行，根据结果汇总实训与课时进度。课程建设侧提供分步 AI 生成、教师确认和课包校验，让教学内容与实际动手过程都有明确的执行依据。

## 核心亮点

| 核心机制 | 如何工作 | 对应用的价值 |
| --- | --- | --- |
| **多形态环境编排** | 以版本化模板描述环境和访问通道，经能力与参数检查、资源准入后创建环境，并管理状态对账和到期回收。 | 将不同实训资源接入统一生命周期，支持按课程需要组织网页与终端实践入口。 |
| **执行结果驱动判定** | 服务端在学习者的运行环境中执行步骤判据，检查超时与输出完整性，并区分通过、未通过和暂不能判定等状态。 | 检查关注操作结果是否满足要求，异常情况也保留明确状态。 |
| **步骤结果汇总学习进度** | 步骤判定继续聚合到实训与课时，实训进度依据服务端检查结果计算。 | 把任务要求、实际操作和学习记录联系起来，为辅导与评价提供过程依据。 |
| **带确认与校验的 AI 课程生产** | 分段生成内容，允许编辑、确认、回退和重试；确认上游内容一致性并校验结构化课包后，导入课程进入审核流程。 | 把 AI 草稿接入可检查的课程生产过程，避免旧阶段结果在上游改动后被直接采用。 |

## 环境与判定如何协作

版本化模板 → 参数与资源准入 → 创建学习者环境 → 环境内执行步骤检查 → 聚合实训与课时结果 → 回收环境

这里的自动检查依赖已配置的环境、判据和运行条件；“暂不能判定”保留为待处理状态。AI 课包生成与导入当前支持文档课时，实验环境和视频等资源按各自流程配置。

## 应用流程

组织课时任务 → 选择与配置环境模板 → 学生操作 → 服务端执行检查 → 教师依据结果辅导

## 条件与范围

- **资源条件**：实训环境与任务模板需按教学场景配置。
- **教师复核**：AI 生成的课程内容由教师核对确认。
- **展示范围**：材料展示产品模块，不承诺具体机构的实施结果。

实训环境、任务模板和 AI 服务需按教学场景配置，具体条件见演示资料。
